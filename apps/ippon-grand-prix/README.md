# 大喜利グランプリ 得点発表ツール（IPPONグランプリ風）

野外学習などのレクで、**5クラス対抗の大喜利**の得点を、IPPONグランプリのような演出で発表するためのツールです。点数ボタン（0〜10）を押すと、点数に合わせた**アニメーション・効果音・紙吹雪**で発表できます。プロジェクタに映してみんなで楽しめます。

- 1ファイルだけで動きます（インストール不要・ネット接続も不要）
- 効果音はツール内で生成（音声ファイル不要）。**会場のスピーカー**につないでください
- Windows の Edge / Chrome で動作（タブレットのブラウザでも可）

## ▶️ 使い方（当日の流れ）

1. `index.html` をダブルクリックしてブラウザで開く
2. **F11キー**で全画面にする（プロジェクタにきれいに映ります）
3. 最初の画面で **「▶ はじめる」** を押す（※この時に音が出せるようになります）
4. 画面下の操作バーで **クラスを選ぶ** → **点数ボタン（0〜10）を押す**
5. ドラムロールでためた後、点数が演出つきで発表されます
6. 次のクラスを選ぶ（または ↺ で「？」に戻す）→ くり返し

> 操作バーは、しばらくマウスを動かさないと自動でかくれます。**マウスを動かす**か、右下の **🎛** を押すと戻ります。

## 🎬 点数ごとの演出

| 点数 | 雰囲気 | 演出 |
|------|--------|------|
| **10** | 満点！ | 金色の大演出・ファンファーレ・画面フラッシュ・紙吹雪どっさり |
| 8〜9 | 高得点 | 金色・はなやかなチャイム・紙吹雪 |
| 6〜7 | good | さわやかな上昇音・少し紙吹雪 |
| 5 | まずまず | ニュートラルな音 |
| 3〜4 | おしい | ひかえめな残念音（青系） |
| 1〜2 | これから | 残念トロンボーン |
| **0** | 0点！？ | ズコー（下降スライド音）＋コミカル演出 |

## ⌨️ キーボード操作（マウスでもOK）

| キー | 動き |
|------|------|
| `0`〜`9` | その点数を発表（例：`7` で7点） |
| `M` | 満点（10点）を発表 |
| `←` `→` | クラスを切り替える |
| `Space` | ドラムロール中なら**今すぐ発表**／発表後は**次へ（？に戻す）** |
| `R` | 「？」に戻す |
| `F` | 全画面の切り替え（F11でもOK） |
| `S` | 音のオン／オフ |
| `H` | 操作バーの表示／非表示 |

> ⚠️ 点数キー（0〜9）とクラス選択キー（1〜5）は重なります。**クラスを変えるときは `←` `→` キー**か、画面下のクラスボタンを使ってください。

## ⚙️ 設定（クラス名・ためる時間）

画面下の **⚙ 設定** から変更できます。

- **クラス名**：「1組」などを、実際のクラス名や班名に変更できます（最大12文字）。空らんにすると初期名に戻ります。
- **ドラムロールでためる**：オン／オフ。オフにすると押した瞬間に発表します。
- **ためる長さ**：0.6〜6.0秒で調整できます（初期は2.8秒）。

設定は同じパソコン・同じブラウザに保存され、次回も引きつがれます。

## 💡 当日のコツ

- 本番前に一度、点数ボタンをいくつか押して**音量とプロジェクタの映り**を確認しておくと安心です。
- 音が出ないときは、①「▶ はじめる」を押したか、② 画面下の **🔊 音 オン** になっているか、③ パソコンとスピーカーの音量、を確認してください。
- 進行役が「○組、何点！？」と煽ってから点数を押すと、ドラムロールで盛り上がります。

## 🛠 技術メモ

- 純粋な HTML / CSS / JavaScript の1ファイル構成。外部ライブラリ・CDN・通信なし。
- 効果音は Web Audio API（オシレーター＋ノイズ）で合成。紙吹雪は Canvas 描画。
- 設定の保存は `localStorage`。
