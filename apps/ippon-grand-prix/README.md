# 大喜利グランプリ 得点発表ツール（IPPONグランプリ風）

野外学習などのレクで、**5クラス対抗の大喜利**の得点を、IPPONグランプリのような演出で発表するツールです。点数（0〜10）をタップすると、得点が **0から1ずつカウントアップ**しながら「ポーン♪」と鳴り、最後に演出つきで発表されます。プロジェクタに映してみんなで楽しめます。

- 1ファイルだけで動きます（インストール不要・ネット接続も不要）
- 効果音はツール内で生成（音声ファイル不要）。**会場のスピーカー**につないでください
- Windows の Edge / Chrome、タッチ画面・タブレットのブラウザで動作

## 🎨 IPPONグランプリ風の見た目

- 黒のダイヤキルト調の背景＋**金色の光線**
- 中央に**八角形の金フレーム**（16:9ワイド画面向けの横長）、その中に**金色LED風の数字**
- 画面下に**お題の金帯**（例：「大御所たちを注意してください」／「Bブロック 第1問」）を表示できます
- **得点が確定すると画面がフラッシュ**＆フレームがキラッと光って「確定」を明示
- **満点（10点）は「INABUN」**のスタンプ＋ファンファーレ＋紙吹雪の大演出

## 👆 操作は「タッチ」前提・押してもバレない

- **指でタップ**して操作します（マウスカーソル前提ではありません）。
- **得点ボタンは、押しても色などの見た目が一切変わりません**。何点を押したか観客に分からないようにするためです。さらに 0 からカウントアップするので、**止まるまで何点か分からずドキドキ**します。
- 画面の**空きスペースをタップ**すると進行できます：
  - ドラムロール中 → **今すぐ発表**
  - 発表後 → **次へ（？に戻す）**
  - 待機中 → 操作バーの表示／非表示

## ▶️ 使い方（当日の流れ）

1. `index.html` をダブルクリックしてブラウザで開く
2. **F11キー**で全画面にする（プロジェクタにきれいに映ります）
3. 最初の画面で **「▶ はじめる」** をタップ（※この時に音が出せるようになります）
4. （任意）**✎ お題** で、その回のお題を金帯に表示
5. 画面下のバーで **点数（0〜10）をタップ**
6. ドラムロール → カウントアップ → 演出つきで発表
7. 画面をタップ（または ↺）して次の発表へ → くり返し

> 操作バーは **▽ボタン**／右下の **🎛**／待機中の**画面タップ**で開閉できます。

## 🎬 点数ごとの演出・効果音

| 点数 | 演出・音 |
|------|----------|
| **10（満点）** | 「INABUN」大スタンプ・ファンファーレ・画面フラッシュ・紙吹雪どっさり・金色LEDが脈打つ。カウントは「一気に」と「最後は1点ずつゆっくり」を 1:2 で出し分け |
| 8〜9 | シンバル＋はなやかなファンファーレ・紙吹雪 |
| 6〜7 | さわやかな上昇音・少し紙吹雪 |
| 4〜5 | やさしい確定音 |
| 1〜3 | 「ブッブー」ブザー（本家の残念音風） |
| **0** | ズコー（下降スライド）＋ブザーでコミカルに |

※ カウントアップ中の「ポーン♪」は、点が増えるごとに少しずつ高くなって盛り上がります。
※ 高得点（6点以上）は、**5点を過ぎたあたりからカウントがゆっくり**になり、途中でランダムに「ためる」ので、最後の1点までドキドキします。
※ 満点以外は、**得点に着いてから確定演出までを1〜2秒ためます**（「まだ上がるかも？」の期待感を出すため）。

## ✎ お題の表示

画面下の **✎ お題** ボタンから、その回のお題と、サブ表示（例：「Aブロック 第1問」）を入力できます。空らんにすると金帯は消えます。

## ⚙️ 設定（ためる時間）

画面下の **⚙ 設定** から変更できます。

- **ドラムロールでためる**：オン／オフ。オフにするとすぐカウントアップします。
- **ためる長さ**：0.6〜6.0秒（初期は2.6秒）。

設定とお題は、同じパソコン・同じブラウザに保存され、次回も引きつがれます。

## ⌨️ キーボード操作（任意・タッチでも全部できます）

| キー | 動き |
|------|------|
| `0`〜`9` | その点数を発表 |
| `M` | 満点（10点）を発表 |
| `Space` | ドラムロール中＝今すぐ発表／発表後＝次へ |
| `R` | 「？」に戻す |
| `F` | 全画面の切り替え（F11でもOK） |
| `S` | 音のオン／オフ |
| `H` | 操作バーの表示／非表示 |

## 💡 当日のコツ

- 本番前に一度、点数をいくつか押して**音量とプロジェクタの映り**を確認しておくと安心です。
- 音が出ないときは、①「▶ はじめる」を押したか、② 画面下の **🔊 音** がオンか、③ パソコンとスピーカーの音量、を確認してください。
- 進行役が「○組、何点！？」と煽ってから点数を押すと、ドラムロール＆カウントアップで盛り上がります。

## 🛠 技術メモ

- 純粋な HTML / CSS / JavaScript の1ファイル構成。外部ライブラリ・CDN・通信なし。
- 効果音は Web Audio API（オシレーター＋ノイズ）で合成。紙吹雪は Canvas 描画。八角フレームは CSS `clip-path`。
- 設定・お題の保存は `localStorage`。
- ロゴ等は本家の意匠を流用せず、IPPONグランプリ風の雰囲気に寄せた独自デザインです（学校行事向けのオマージュ）。
