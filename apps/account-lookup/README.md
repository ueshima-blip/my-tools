# アカウント確認ツール（生徒アカウント・パスワード照会）

生徒が自分の **Googleアカウント／パスワード**・**端末番号／暗証番号**・**まなびポケット学校コード** を忘れたときに、
教職員が **年・組・氏名（ひらがな）** からすばやく調べて知らせるための、教職員用ツールです。

**単一HTMLファイル製・完全オフライン動作**（インストール・サーバー・インターネット不要）。生徒情報を外部へ送信することは一切ありません。

> 🔐 **個人情報・パスワードを扱います。** 取り扱いには十分ご注意ください（下の「セキュリティ」を必ずお読みください）。

## 2つのモード（自動で切り替わります）

このツール（`index.html`）は、開く人・ファイルによって2つの顔を持ちます。

| モード | だれが使う | 何ができる |
|---|---|---|
| **管理者モード** | あなた（名簿を管理する先生） | Excel名簿を読み込み、**パスワードで暗号化した「保護版HTML」を作成** |
| **閲覧モード** | 配布された先生 | 保護版HTMLを開き、**パスワードで解錠**して検索 |

`index.html` をそのまま開くと**管理者モード**、暗号データが埋め込まれた**保護版HTML**を開くと**閲覧モード**になります。

## 使い方

### 【管理者】保護版HTMLを作って配る（最初に1回＋名簿更新時）

1. テンプレート（下記）に名簿を入力して保存する。
2. `index.html` をブラウザで開く（管理者モード）。
3. **① 名簿（Excel）を読み込む**。
4. **② 保護版HTMLを作成** … 「閲覧用パスワード」を決めて入力 → **「🔐 保護版HTMLを作成」**。
   `アカウント確認（保護版）.html` がダウンロードされます。
5. この **保護版HTML を共有フォルダ等に置き**、先生方には **パスワードを別の方法（口頭など）で**伝える。
   - 🎉 これで **生のExcelを共有フォルダに置く必要はありません**（保護版には暗号化された名簿だけが入っています）。

### 【配布された先生】保護版HTMLで調べる

1. 共有フォルダの `アカウント確認（保護版）.html` をブラウザで開く（閲覧モード）。
2. **パスワードを入力して「解錠する」**。
3. 「年」「組」を選び、「氏名（ひらがな）」を入力（一部・カタカナでも可）→ 該当生徒の情報が表示されます。
4. 必要な情報を読み上げる／「コピー」／「🖨 印刷」して知らせる。
5. 用が済んだら **「🔒 ロック」** または **「🧹 画面を消す」** で情報を画面から消す。

> ロックすると、復号した情報はメモリから消え、再度パスワードが必要になります。

## 表示できる情報

検索すると、その生徒の次の情報を表示します。

- 年 / 組 / 番 / 氏名（漢字）
- Googleアカウント / **Googleパスワード**
- 端末番号 / **端末暗証番号**
- **まなびポケット学校コード（全員共通）**

**Googleパスワード・端末暗証番号**は、最初は伏字（••••）で「表示」を押したときだけ見えます（のぞき見対策）。各項目に「コピー」ボタン、生徒に渡す「🖨 用紙の印刷」もあります。

## 事前に用意する Excel 名簿

- 配布用のひな形：[`アカウント名簿テンプレート.xlsx`](アカウント名簿テンプレート.xlsx)
  （管理者モードの「📥 記入用テンプレートをダウンロード」と同じ内容）

テンプレートは次の形です。**見出しの行（3行目）は消さないでください。**

| 行 | 内容 |
|---|---|
| 1行目 | 「まなびポケット学校コード（全員共通）」のラベル |
| 2行目（A2） | **まなびポケット学校コード**の値を **1つだけ**入力（全クラス共通） |
| 3行目 | 見出し（下の表） |
| 4行目以降 | 生徒データ（1人1行） |

3行目の見出し（＝生徒データの列）は次のとおりです。

| 列 | 見出し | 内容 | 例 |
|---|---|---|---|
| A | 年 | 学年 | `2` |
| B | 組 | クラス | `3` |
| C | 番 | 出席番号 | `15` |
| D | 氏名（漢字） | 氏名（漢字） | `鈴木 一郎` |
| E | 氏名（ひらがな） | ふりがな（**検索に使います**） | `すずき いちろう` |
| F | Googleアカウント | メールアドレス等 | `ichiro.suzuki@example-jhs.ed.jp` |
| G | Googleパスワード | パスワード | `Suzuki-9012` |
| H | 端末番号 | タブレット等の管理番号 | `T-115` |
| I | 端末暗証番号 | 端末のパスコード | `0830` |

- **検索は「氏名（ひらがな）」で行います。** ひらがなで入れてください（カタカナでも検索できます）。
- **先頭の 0**（例 `0042`）が消えないよう、テンプレートの該当列は「文字列」設定です。手入力で作る場合はその列を文字列にするか、先頭に `'` を付けてください。
- 見出しは表記ゆれに対応します（例：`ふりがな`→氏名（ひらがな）、`暗証番号`→端末暗証番号、`出席番号`→番 など）。

### テンプレートの再生成（任意）

体裁つきテンプレートは Python（`openpyxl`）でも再生成できます（通常は不要）。

```bash
python3 build_template.py   # → アカウント名簿テンプレート.xlsx を出力
```

## 🔐 セキュリティ

- **暗号化方式**：ブラウザ標準の Web Crypto（**AES‑GCM 256bit**、鍵は **PBKDF2‑SHA256・20万回**でパスワードから生成）。外部ライブラリ・通信なし。
- **保護版HTMLに入っているのは暗号文だけ**です。正しいパスワードがなければ名簿は読み出せません（Excelには戻せません）。共有フォルダに置く前提で設計しています。
- **パスワードはファイルに保存されません**。配布先へは口頭など別経路で伝えてください。**強いパスワード**（8文字以上・推測されにくいもの）を推奨します。
- **復号した情報はメモリ上だけ**で扱い、「ロック」やタブを閉じると消えます（保存しません）。共用PCでも残りにくい設計です。
- できれば **共有フォルダ自体も教職員のみ閲覧可**に設定してください（多層の安全策）。
- 注意：パスワードが弱いと、保護版ファイルを入手した第三者に総当たりで破られる可能性があります。**強いパスワード**と**ファイルの保管場所の管理**の両方が大切です。
- 印刷した用紙にはパスワードが載ります。本人へ確実に手渡してください。

## 動作環境

- 最近の **Chrome / Edge / Safari / Firefox**。暗号化は「安全なコンテキスト」で動作します。
  - 共有フォルダのファイルをダブルクリックして開く（`file://`）方法で動きます。
  - もし「暗号化機能が使えません」と出る環境では、**https のURL（GitHub Pages 等）**から開いてください。
- インストール不要。PC・タブレットのブラウザで利用できます。
