# アカウント確認ツール（生徒アカウント・パスワード照会）

生徒が自分の **Googleアカウント／パスワード** や **端末番号／暗証番号** を忘れたときに、
教職員が **年・組・氏名（ひらがな）** からすばやく調べて知らせるための、教職員用ツールです。

事前に名簿（Excel）を用意し、このツール（`index.html`）に読み込んで使います。
**単一HTMLファイル製・完全オフライン動作**で、読み込んだ名簿や生徒情報を外部へ送信することは一切ありません。

> 🔐 **個人情報・パスワードを扱います。** 取り扱いには十分ご注意ください（下の「セキュリティ／取り扱い注意」を必ずお読みください）。

## 表示できる情報

検索すると、その生徒の次の情報を一覧表示します。

| 年 | 組 | 番 | 氏名（漢字） | Googleアカウント | Googleパスワード | 端末番号 | 端末暗証番号 |
|---|---|---|---|---|---|---|---|

加えて、**まなびポケット学校コード（全員共通）** も表示します（読み込み直後の表示と、各生徒のカード・印刷用紙の両方に出ます）。

- **Googleパスワード・端末暗証番号**は、最初は伏字（••••）で表示され、「表示」ボタンを押したときだけ見えます（のぞき見対策）。
- 各項目に「コピー」ボタンがあり、ワンクリックでコピーできます。
- 「🖨 この生徒の用紙を印刷」で、本人に手渡す用紙（おしらせ）を印刷できます（まなびポケット学校コードも記載されます）。

## 使い方

1. `index.html` を Chrome／Edge／Safari などのブラウザで開く（ダブルクリック）。
2. **① 名簿（Excel）を読み込む** … 名簿の `.xlsx` をドラッグ＆ドロップ、またはクリックして選択。
   - まだ名簿が無い場合は **「📥 記入用テンプレート（Excel）をダウンロード」** から空のひな形を入手し、記入してから読み込んでください。
3. **② 生徒を検索する** … 「年」「組」を選び、「氏名（ひらがな）」を入力（一部だけでもOK）。
   - 1人に絞られると、その生徒の情報カードが表示されます。複数いるときは一覧から名前を選びます。
4. 必要な情報を読み上げる／「コピー」する／「印刷」して知らせます。
5. **用が済んだら「🧹 画面を消す」** を押して、画面に情報を残さないようにします。

## 事前に用意する Excel 名簿

- 配布用のひな形：[`アカウント名簿テンプレート.xlsx`](アカウント名簿テンプレート.xlsx)
  （アプリ内の「記入用テンプレートをダウンロード」と同じ内容）

テンプレートは次の形になっています。**見出しの行（3行目）は消さないでください。**

| 行 | 内容 |
|---|---|
| 1行目 | 「まなびポケット学校コード（全員共通）」のラベル |
| 2行目（A2） | **まなびポケット学校コード**の値を **1つだけ**入力（全クラス共通） |
| 3行目 | 見出し（下の表） |
| 4行目以降 | 生徒データ（1人1行） |

3行目の見出し（＝生徒データの列）は次のとおりです。

| 列 | 見出し | 内容 | 例 |
|---|---|---|---|
| A | 年 | 学年 | `2` |
| B | 組 | クラス | `3` |
| C | 番 | 出席番号 | `15` |
| D | 氏名（漢字） | 氏名（漢字） | `鈴木 一郎` |
| E | 氏名（ひらがな） | ふりがな（**検索に使います**） | `すずき いちろう` |
| F | Googleアカウント | メールアドレス等 | `ichiro.suzuki@example-jhs.ed.jp` |
| G | Googleパスワード | パスワード | `Suzuki-9012` |
| H | 端末番号 | タブレット等の管理番号 | `T-115` |
| I | 端末暗証番号 | 端末のパスコード | `0830` |

- **まなびポケット学校コードは「全員共通」**です。テンプレートの **A2 セルに1つだけ**入力してください（生徒ごとに入れる必要はありません）。
  - 参考：列見出しに「まなびポケット学校コード」という列を作って入力しても読み取れます（その場合は最初に入力された値を全員共通として使います）。
- **検索は「氏名（ひらがな）」で行います。** ひらがなで正しく入れてください（カタカナでも検索できます）。
- **端末暗証番号などの「先頭の 0」**（例 `0042`）はそのまま保てるよう、テンプレートのその列は「文字列」設定にしてあります。手入力で作る場合は、その列を文字列にするか、先頭に `'`（アポストロフィ）を付けてください。
- 見出しは多少の表記ゆれに対応します（例：`ふりがな`→氏名（ひらがな）、`パスワード`→Googleパスワード、`暗証番号`→端末暗証番号、`出席番号`→番 など）。

### テンプレートの再生成

体裁つきのテンプレートは Python（`openpyxl`）で再生成できます。

```bash
python3 build_template.py   # → アカウント名簿テンプレート.xlsx を出力
```

## 🔐 セキュリティ／取り扱い注意（重要）

このツールは、生徒の**パスワードを含む個人情報**を扱います。次の点にご注意ください。

- **外部送信はありません。** 名簿の読み込み・検索・表示はすべて、開いた端末の中だけで完結します（インターネット接続も不要）。アプリ本体（`index.html`）には生徒情報は含まれていません。
- **情報の実体は Excel 名簿です。** 名簿ファイルは、**かぎのかかった場所**（権限を絞った共有フォルダ、暗号化したUSB、Excel自体のパスワード保護など）に保管してください。不要なコピーは作らない／消す。
- **画面ののぞき見に注意。** パスワード・暗証番号は最初は伏字です。人前では「表示」を使わない、用が済んだら「🧹 画面を消す」を押す、を徹底してください。
- **この端末には保存されません。** 読み込んだ名簿はメモリ上だけで扱い、ブラウザを閉じると消えます（毎回 Excel を読み込む運用です）。共用PCでも情報が残りにくい設計です。
- **印刷した用紙**にはパスワードが載ります。本人へ確実に手渡し、放置・誤配布のないようご注意ください。

## 動作環境

- 単一HTMLファイル。インストール・サーバー不要。インターネット接続も不要。
- 最近の Chrome／Edge／Safari／Firefox で動作（Excel 解凍に標準の `DecompressionStream` を使用）。
- PC・タブレットのブラウザで利用できます。
