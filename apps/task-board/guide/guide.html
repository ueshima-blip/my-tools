タスクボード　かんたんガイド

本日／2週間以内のタスクを自動でならべる、デスク常駐のタスク管理ツール
やることに「締め切り・作業する日・作業する週」を決めておくと、その日・その時期が来たら自動で画面に並びます。 終わったらチェックで消化。毎日・毎週の定型は「定期タスク」で自動化できます。データは各自の端末内に保存され、外部には送られません。
本日／2週間以内に自動振り分け 定期タスク（毎日・毎週・毎月） 祝日ずらし おやすみ期間 3デザイン切替 授業前に目隠し
▲ 画面イメージ（上＝本日／下＝2週間以内）

1インストール（アプリとして使う）

  1. Chrome または Edge で、次のアドレスをクリック（ブラウザで開きます）
    https://edu-tools-jp.github.io/koumu/taskboard/
  2. アドレスバー右端の「インストール」アイコン（□に↓）をクリック →「インストール」
    アイコンが無いときは、右上「…」→「アプリ」→「このサイトをアプリとしてインストール」
  3. タブやアドレスバーの無い専用ウィンドウで開きます。次回からはスタートメニュー（やタスクバー）のアイコンで起動できます
  4. デスクトップにアイコンを作る（任意）：スタートメニューの「タスクボード」をデスクトップへドラッグ（Chrome は chrome://apps → 右クリック →「ショートカットを作成」→「デスクトップ」）
    最近の Edge はインストール時にデスクトップのショートカットを自動作成しません。上の方法で作れます。
💡 初回のみインターネット接続が必要です。一度開けば、その後はオフラインでも起動できます。管理端末で「インストール」がグレーで選べない場合は、配布元の先生にご相談ください。

2使い方

タスクを追加：画面上の「＋ タスクを追加」から、締め切り・作業する日・作業する週・優先を設定。各段の下の欄に書いて Enter でもすぐ追加（末尾 ! で優先）。
自動で並ぶ：作業日が今日なら【本日】、2週間以内なら【2週間以内】へ。15日より先は「予定 N」で控え、近づくと出ます。
完了・編集：チェックボックスをクリックで完了（元に戻すつき）。文字はダブルクリックで編集、☆で優先、✕で削除。
定期タスク：右上「…」→「🔁 定期タスクを管理」。毎日／毎週◯曜／毎月◯日を登録すると自動で出ます（祝日ずらし・おやすみ期間つき）。
見た目・目隠し：右上 ◐ でデザイン切替（NEON／GLASS／MONO）。授業前は ◑ か Esc で中身を時計表示に。
隠す・小さく：画面ごと隠すなら Win+D。ウィンドウの端をドラッグして小さくすれば、付箋のように置けます。
