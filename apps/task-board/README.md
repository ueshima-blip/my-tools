# タスクボード

仕事のタスクを、**上に「本日のタスク」・下に「今週中のタスク」**と縦に並べて表示するツールです。タスクに「締め切り・作業する日・作業する週」を決めておくと、**その日・その週になったら自動で表示**されます（作業日が今日になると自動で「本日」に上がってきます）。

**インストール不要・完全オフライン・外部送信なし。** `index.html` をダブルクリックするだけで使えます（Windows／Edge・Chrome を想定）。デザインは **NEON / GLASS / MONO** の3種類を切り替えられます。

> 📦 **他の先生に配るとき**は、この `task-board` フォルダごと渡してください（フォルダ名は `タスクボード` に変えてOK）。中の **`はじめにお読みください.txt`** に、先生向けのやさしい説明が入っています。配布用の ZIP では、分かりやすいよう本体ファイルを **`タスクボード.html`** という名前にしています（リポジトリ上は GitHub Pages / インストール用に `index.html` のままです）。

## 使い方（かんたん）

1. **開く**：フォルダの中の **`index.html` をダブルクリック**（既定のブラウザで開きます）
2. **追加**：「**＋ タスクを追加**」から
   - **締め切り**（任意）… 〆チップで表示（今日・過ぎた分は赤）
   - **作業する日**（任意・`今日`／`明日`ボタン）… その日になったら「本日」に自動表示
   - **作業する週**（今週／来週／指定なし）… その週のあいだ「今週」に表示
   - **優先**（先頭に表示）
3. **完了**：丸をクリック → 下の「完了」へ。`完了を消す`でまとめて削除（**元に戻す**つき）
4. **編集**：文字をダブルクリック（または ✎）／**優先**：☆ ／**削除**：✕
5. **サッと追加**：各段の下の入力に書いて `Enter`（末尾 `!` で優先）
6. **デザイン切替**：右上の ◐ ボタンで NEON → GLASS → MONO（選んだ色は保存）

来週以降のタスクは「予定 N」とだけ表示され、その週になると自動で出てきます。

## デスクトップにコンパクトなカードとして置く

ブラウザで開いたあと、**ウィンドウを小さくして画面のすみに置く**だけで、付箋のようなカード表示になります（インストール不要）。

1. `index.html`（配布版は `タスクボード.html`）を開く
2. ブラウザ**ウィンドウの角・ふち**をドラッグして、**縦長・小さめ**（スマホくらいの幅）にする
3. 画面の**右すみ**などへ移動 → カードだけが置かれた見た目に

**ワンクリックで開けるようにする（デスクトップにアイコン）**

`タスクボード.html` を**右クリック → 送る → デスクトップ（ショートカットを作成）**。できたアイコンをダブルクリックすれば一発で開けます。

> Chrome/Edge の「ショートカットを作成」「アプリとしてインストール」は、学校・職場の**管理端末ではポリシーで無効化**（メニューが灰色）されていることがあります。その場合でも、上の **Windows の「送る → デスクトップ」** ならショートカットを作れます。

## 授業前などにサッと隠す

- **中身だけ隠す**：右上の ◑ ボタン、または `Esc` キー → 画面が時計表示になります（もう一度で戻る）
- **ウィンドウごと隠す**：`Win`＋`D`（デスクトップ表示）。`Win`＋`D` でまた戻せます

## データの保存について

- タスクは**この端末のブラウザの中**に保存されます（外部には送られません）。
- **フォルダは同じ場所で使ってください。** 別の場所へ移すと、前のタスクが見えなくなることがあります（消えたわけではありません）。
- 端末を変える・念のため保存したいときは、右上 `⋯` メニューの **「書き出す（.json）」** でバックアップ → 移した先で **「読み込む」**。

## 配る人向けのメモ

- 配布は**フォルダごとコピー**するだけ。相手はインストール不要で、**`タスクボード.html`**（配布用ZIP内。リポジトリ直下では `index.html`）をダブルクリックすれば使えます。
- ブラウザの**タブ**として開きます（それで正常です）。ウィンドウを小さくして画面の端に置けば、付箋のようなカードとして使えます（上の「デスクトップにコンパクトなカードとして置く」を参照）。
- 先生向けの説明は `はじめにお読みください.txt`（メモ帳で開けます）。
- 起動用のバッチ（.bat）は同梱していません。環境によって「ブラウザが開くだけ」になり分かりにくいため、**`タスクボード.html` をダブルクリック**の一本にしています。

## アプリのように「枠なしの窓」で表示する（インターネット接続・任意）

タブや住所バーの無い**アプリ窓**で使いたい場合は、「アプリとしてインストール」します。**これは `https` のページでのみ可能**で、ローカルの `タスクボード.html`（file://）では出ません。

1. Chrome/Edge で **`https://ueshima-blip.github.io/my-tools/apps/task-board/`** を開く（GitHub Pages 有効化が前提）
2. **アドレスバー右端の「インストール」アイコン**（□に↓）をクリック →「インストール」
   - 出ない場合：右上「⋮／…」→「アプリ」/「ページをアプリとしてインストール」から
3. 枠なしのアプリ窓で開き、スタート/タスクバー/デスクトップのアイコンで起動できます

> - **file:// で「ショートカットを作成」が灰色**なのは、file:// では作れない（＋管理端末ではポリシーで無効の）ため。アプリ窓が欲しいときは上の **https のページ**から入れてください。
> - **`chrome://policy` / `chrome://management`** で、ブラウザが組織ポリシー管理下か確認できます（学校アカウントでChromeにサインインしていると、私用端末でも管理下になり、インストールが無効なことがあります）。
> - 管理設定でインストールできない場合は、「配る人向けのメモ」の**ダブルクリック＋窓を小さく**でお使いください。
