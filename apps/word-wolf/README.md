# ワードウルフ 進行アプリ

クラスの **4〜6人グループ** で遊ぶ「ワードウルフ」を、テレビ／プロジェクタに映して進めるためのアプリです。お題配り → お話しタイム（タイマー）→ 指差し → ウルフ発表まで、画面の案内どおりに進められます。

## 🐺 ワードウルフとは

- グループのほとんどの人は **同じお題（市民）**、でも 1〜2人だけ **少し違うお題（ウルフ）** を持ちます。
- お題を直接言わずに会話して、誰がウルフ（みんなと違うお題の人）かを当てるゲームです。

## ▶️ 遊び方（画面の流れ）

1. **設定** … このグループの **人数（4／5／6）**、**ウルフの人数（1／6人なら2も可）**、**お題のジャンル**を選んで「お題を配る」。
2. **お題確認** … 「○番の人」と表示されます。その番号の人だけが画面の前に来て、中央のボタンを **長押し** している間だけ自分のお題が見えます（指を離すと隠れる＝のぞき見防止）。確認したら「次の人へ」。これを全員ぶん順番に。
3. **お話しタイム** … 3分タイマー（2／3／5分に変更可）。自分のお題を言わないように、それっぽく会話します。
4. **指差しタイム** … 「せーの！」のカウントに合わせて、ウルフだと思う人を全員でいっせいに指差します。
5. **結果発表** … 何番の人がウルフだったか、市民・ウルフそれぞれのお題を表示します。「同じ人数でもう一回」ですぐ次のラウンドへ。

## 🙋 人数がそろわない問題（4・5・6人混在）への対応

クラスでグループ分けすると、4人・5人・6人が混ざってしまうのが普通です。このアプリは **グループごとに人数を選んでから始める** 作りなので、混在していても問題ありません。

- **各グループの番（ラウンド）の最初に、そのグループの人数を選ぶだけ。** 余り番号が出ないので「いない番号」は表示されません。
- **ウルフの人数は人数に応じて自動調整。** 4・5人は1人固定、6人は1人か2人を選べます（人数が多いとウルフ1人だと当てやすいため）。
- 1台のテレビを各グループが順番に使う運用でも、グループが変わるたびに人数を選び直せば、そのまま続けて遊べます。

> 補足：もし「全グループを同じ人数にそろえたい」場合は、少人数グループに先生が入る／4人グループだけ別ジャンルにする、などの運用も可能ですが、基本はアプリ側で人数を選べばOKです。

## 📺 使う場面・端末

- 教室のテレビ／プロジェクタ（PC）や、タブレットでの表示を想定。文字を大きく、暗めの背景で見やすくしています。
- 効果音（カウントやタイマー終了）はブラウザの音源で鳴らすため、追加ファイルは不要です。音が出せない環境でも動作します。

## 🗂 ファイル

- `index.html` … これ1つで動きます（外部ライブラリ不要）。
- お題ペアは `index.html` 内の `TOPICS` を書き換えれば自由に追加・変更できます。
