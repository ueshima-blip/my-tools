# 自動ルビ振り（ふりがな）— かんたん配布パッケージ

Word の文章の漢字に、**ふりがな（ルビ）を自動で振る**マクロです。
元になっているのは「初心者備忘録さん」「福原裕之の科学グッズ」さんが公開されている Word マクロで、Word 内蔵の「ふりがなガイド」を自動で実行する仕組みです（Windows 版 Word 専用）。

このフォルダは、そのマクロを **「テキストをコピーして VBA に貼り付ける」作業なしで、他の先生に配れる形**にまとめたものです。

---

## 😣 これまでの配り方の問題

配られた先生は、毎回こんな作業が必要でした。

1. Word を開く → 表示 → マクロ → 名前を入力 → 作成
2. VBA という黒っぽい画面が開く
3. **もとからある文字を全部消す**
4. **長いプログラムをコピーして貼り付ける**
5. 保存する

→ 3・4 のあたりで「どこを消すの？」「貼る場所が違う」と**つまずく先生が続出**。これが広まらない一番の原因でした。

## 🎯 新しい配り方（コピペ作業ゼロ）

**マクロを“入れ込み済み”の Word ファイルを1個作って、それを配るだけ**にします。
受け取った先生は **VBA 画面を一度も開きません**。

配り方は2通り。おすすめは方法Aです。

| | 方法A：**インストール版**（イチオシ） | 方法B：**そのまま版**（インストール不要） |
|---|---|---|
| 配るもの | `AutoRuby.dotm` ＋ `install.bat` | `自動ルビ.docm` 1個 |
| 受け取る先生の操作 | `install.bat` をダブルクリック → Word 再起動 | ファイルを開いて、その中で作業 |
| 使える範囲 | **これ以降ひらく全部の Word 文書** | その1ファイルの中だけ |
| マクロの警告 | **出ない**（安全な場所に入るため） | 開くとき「コンテンツの有効化」を1回押す |
| 向いている人 | パソコンに置いて長く使う先生 | とりあえず1回試したい先生 |

> 💡 どちらの方法でも、受け取る先生は**プログラムを一切さわりません**。配る側が下の「作る手順」で1回だけ準備します。

## 👩‍🏫 受け取る先生むけ：使い方（配布物にこの3行を添えるだけ）

> 📄 **配布用の使い方ガイド**を `manual/` に用意しています。配布物に同梱するか、印刷して一緒に渡すのがおすすめです。
> - [`manual/かんたん使い方ガイド_表示マクロ.pdf`](manual/かんたん使い方ガイド_表示マクロ.pdf)（**A4 1枚・いちばん簡単**／「表示→マクロ」で実行。設定不要なので配布におすすめ）
> - [`manual/かんたん使い方ガイド_方法ア.pdf`](manual/かんたん使い方ガイド_方法ア.pdf)（A4 1枚／リボンに「ルビ振り」タブを作る方式）
> - [`manual/使い方マニュアル.pdf`](manual/使い方マニュアル.pdf)（A4 3ページ／図解多めのくわしい版）

### 方法A（インストール版）を受け取ったら
1. `install.bat` を **ダブルクリック**（「実行」をきかれたら はい／実行）
2. 開いている **Word をいったん全部閉じて、もう一度開く**
3. リボンに出てくる **「ルビ振り」タブ**のボタン、または **表示 → マクロ** から実行
   - 元に戻したいときは `uninstall.bat` をダブルクリック

### 方法B（そのまま版）を受け取ったら
1. `自動ルビ.docm` を **ダブルクリックで開く**
2. 上に出る黄色い帯の **「コンテンツの有効化」を1回押す**
3. その文書に文章を打つ／貼り付けて、**「ルビ振り」タブ**または **表示 → マクロ** から実行

### 4つのボタンの意味（共通）
| ボタン | はたらき |
|---|---|
| **全文にルビ** | 文書全体の漢字すべてにルビ |
| **全文にルビ（初出のみ）** | 同じ漢字は最初の1回だけルビ（プリント向き） |
| **選択範囲にルビ** | マウスで選んだ範囲の漢字すべてにルビ |
| **選択範囲にルビ（初出のみ）** | 選んだ範囲で、同じ漢字は最初の1回だけ |

## 🛠 配る側むけ：配布ファイルを作る手順（準備は1回だけ）

すでにマクロが動く Word ファイルをお持ちなら、**5分**で配布物が作れます。

### STEP 1. マクロを“きれいに”入れ直す（コピペより簡単）
このフォルダの [`macro/AutoRuby.bas`](macro/AutoRuby.bas) は、**ファイルとして読み込む（インポート）**だけで取り込めます。コピー＆貼り付けのように「どこを消す・どこに貼る」で迷いません。
いまお持ちの「古いマクロを貼り付けただけの Word ファイル」を、次の手順できれいに入れ直します。

**① AutoRuby.bas をパソコンに保存する**
GitHub でこのファイルの画面を開き、右上の **［Download raw file］（↓ のアイコン）** をクリックして保存します。
- ファイル名が `AutoRuby.bas` になっているか確認（`AutoRuby.bas.txt` になっていたら、末尾の `.txt` を消す）。
- このファイルは日本語版 Word の VBA に合わせて **Shift-JIS（CP932）** で保存しています。GitHub の画面上ではコメントが文字化けして見えることがありますが、**ダウンロードして取り込めば正しく表示されます**（テキストエディタで開いて UTF-8 で保存し直すと、取り込み時に文字化けするので注意）。

**② Word ファイルを開いて、VBA 画面を出す**
古いマクロを貼り付けた Word ファイルを開き、キーボードの **Alt ＋ F11** を押します（VBA エディタが開きます）。

**③ 古いマクロ（モジュール）を先に取り除く　← ここが大事**
左上の「プロジェクト」窓で、貼り付けたマクロのモジュール（例：`NewMacros` や `Module1`）を **右クリック →「○○ の解放」**。
「エクスポートしますか？」と聞かれたら **［いいえ］** を押します。
- これをしないと、同じ名前のマクロが2つになり、実行時に「名前が適切ではありません」エラーが出ます。

**④ AutoRuby.bas を読み込む（インポート）**
メニュー **ファイル →「ファイルのインポート」** で `AutoRuby.bas` を選びます（または、保存した `AutoRuby.bas` を「プロジェクト」窓に**ドラッグ＆ドロップ**）。
→ `AutoRuby` というモジュールが追加されます。

**⑤ 取り込めたか確認する**
「プロジェクト」窓の `標準モジュール` に **`AutoRuby`** が増えていれば成功です。ダブルクリックすると `Public Sub MakeRubiAll` などが見えます。確認したら **Alt ＋ F11** で Word に戻ります。

### STEP 2-A. 方法A用：テンプレート（.dotm）として保存
1. ファイル → 名前を付けて保存
2. ファイルの種類で **「Word マクロ有効テンプレート (*.dotm)」** を選ぶ
3. ファイル名を **`AutoRuby`** にして保存（→ `AutoRuby.dotm` ができる）
4. できた `AutoRuby.dotm` を、このフォルダの [`installer/`](installer/) の中の
   `install.bat` ／ `uninstall.bat` ／ `open_startup_folder.bat` と**同じフォルダにまとめ**、
   フォルダごと ZIP にして配る

### STEP 2-B. 方法B用：そのまま使う文書（.docm）として保存
1. ファイル → 名前を付けて保存
2. ファイルの種類で **「Word マクロ有効文書 (*.docm)」** を選ぶ
3. ファイル名を **`自動ルビ`** にして保存 → この1ファイルを配るだけ

### STEP 3.（任意）リボンに「ルビ振り」ボタン／タブを出す
ボタンがあると、表示→マクロを開かずワンクリックで使えます。
**※ AutoRuby.bas を取り込んだだけでは「ルビ振り」タブは出ません**（マクロは入りますが、タブは別に用意します）。やり方は2通りです。

#### 方法ア：自分の Word にすぐ出す（ツール不要・いちばん簡単）
リボンのユーザー設定で、自分専用のタブを作ります。**そのパソコンだけ**に出ます（ファイルには付かないので、他の先生には引き継がれません）。

1. **ファイル → オプション → リボンのユーザー設定**
2. 右側で **［新しいタブ］** をクリック →「新しいタブ(ユーザー設定)」ができる
3. それを選び **［名前の変更］** で「**ルビ振り**」に。中の「新しいグループ」も「**自動ルビ**」などに変更
4. 左側の **「コマンドの選択」を「マクロ」** に切り替える
5. `MakeRubiAll` などを選び、右の「自動ルビ」グループを選んだ状態で **［追加］** （4つとも）
6. 各ボタンを選んで **［名前の変更］** で「全文にルビ」などに（任意）→ **［OK］**

#### 方法イ：ファイルに埋め込む（配布向け・開いた先生みんなにタブが出る）
`customUI14.xml` を Word ファイルに埋め込むと、**ファイルと一緒にタブが移動**します。他の先生に配るならこちら。無料ツールを1回使います。

1. 無料の **「Office RibbonX Editor」** を入手して起動
   （「Office RibbonX Editor」で検索／GitHub の fernandreu/office-ribbonx-editor で配布）
2. STEP 2 で作った `AutoRuby.dotm`（または `.docm`）を開く
3. メニュー Insert → **Office 2010+ Custom UI Part** を選ぶ
4. 追加された `customUI14.xml` の中身を、このフォルダの
   [`ribbon/customUI14.xml`](ribbon/customUI14.xml) の中身に**置きかえて保存**
5. Word で開き直すと、リボンに **「ルビ振り」タブ**が出ます

> どちらも面倒なら、タブ無しでも **表示 → マクロ** から実行できます。
> 一番手軽なボタンは **ファイル → オプション → クイックアクセスツールバー → 「マクロ」から4つを追加**（XML 不要・画面最上部に常に表示）。

## ❓ 困ったとき

- **Mac で動かない** … このマクロは **Windows 版 Word 専用**です（内蔵ふりがな機能を使うため）。
- **`install.bat` が「実行できない」「ブロックされた」** … 学校の PC でバッチが止められている場合は、
  `open_startup_folder.bat` でフォルダを開き、`AutoRuby.dotm` を**手でドラッグして入れて**ください。
  それも難しければ、方法B（`.docm` をそのまま開く）を案内すれば確実です。
- **「ルビ振り」タブが出ない** … 方法Aは **Word の再起動**が必要です。再起動しても出ないときは
  表示 → マクロ から実行できるか確認してください（タブが無くてもマクロは使えます）。
- **読みが違う漢字がある** … Word／IME の自動判定の読みです。気になる箇所は、その漢字を選んで
  ホーム → ルビ（亜のアイコン）から手で直せます。
